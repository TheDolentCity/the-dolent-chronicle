I don't mind the dragon game that much, but I really only like playing or running it at level 1. This does not appeal to most dragon game enjoyers, so we tend to go our separate ways, only joining together for the _Mothership_ or more trad games I happen to run. But the thing is, I can _always_ get people to sign up for campaigns if I promise to use the dragon game. No matter the premise, it is far easier to get a dragon game going than it is to try and sell players on any of my own games.

So I made a dragon game that appeals to me more, in the hope that I can get more player interest and also not suffer the slings and arrows of 2 hour combat encounters at level 3. I call it...

## [Rudiment](/manuscripts/rudiment)

Merriam Webster defines rudiment as "a basic principle or element" and also "something unformed or undeveloped". Both are appropriate here. I aim to create a "basic" dragon game experience, and the existing version is an undeveloped ashcan that I'll update over time.

Rudiment is the same bones as the dragon game, but condenses the framework to serve the kinds of stories I like to tell. A level 1 Barbarian can take anywhere from 3-4 hits from a longsword. That is still quite heroic! And at level 3, they can probably take 1-2 more. But that's a far cry off from the durability of a level 3 rules-as-written Barbarian. The harsher lethality mostly comes from those traditionally squishy classes like Wizard and Sorcerer, but they get world-ending magic spells, so that seems fair to me.

I won't dive into all the rules in this post, it's a [6 minute read](/manuscripts/rudiment) if you're interested. I will periodically update the rules, but I expect that to happen more frequently come Winter, when I hope to run a _Rudiment_ campaign. If you do read the rules, I would love feedback, especially from the dragon game enjoyers.
